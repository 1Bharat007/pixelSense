# Support

## Getting Help

If you're having trouble with PixelSense, here's how to get help — in order of effectiveness:

### 1. 📖 Check the Documentation

- [README](README.md) — Overview, quick start, and architecture
- [FAQ](FAQ.md) — Answers to common questions
- [Features](FEATURES.md) — What's implemented, what's mocked, what's planned
- [Architecture](ARCHITECTURE.md) — How the system works

### 2. 🔍 Search Existing Issues

Your question may already have been answered. Search [open and closed issues](https://github.com/1Bharat007/pixelSense/issues?q=is%3Aissue) before creating a new one.

### 3. 💬 Start a Discussion

For questions, ideas, or general conversation, use [GitHub Discussions](https://github.com/1Bharat007/pixelSense/discussions). This is the best place for:

- "How do I..." questions
- Feature brainstorming
- Sharing your setup or use case

### 4. 🐛 File an Issue

If you've found a bug or have a concrete feature request, [open an issue](https://github.com/1Bharat007/pixelSense/issues/new/choose). Please use the appropriate template and include:

- Your Windows version
- Your display configuration (resolution, scaling, monitor count)
- Steps to reproduce the problem
- Expected vs. actual behavior

## What to Expect

- **Issues**: We aim to triage new issues within one week
- **Pull Requests**: We review PRs as quickly as possible; complex changes may take longer
- **Discussions**: Community-driven; maintainers participate when available

## What This Project Does Not Offer

- Paid support
- Service level agreements
- Real-time chat support

PixelSense is maintained by volunteers. We appreciate your patience.
