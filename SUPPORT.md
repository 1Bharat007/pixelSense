# Support

## Where to get help
If you are having trouble with PixelSense, please follow these steps:
1. **FAQ**: Check our [Frequently Asked Questions](docs/community/faq.md).
2. **GitHub Discussions**: Ask questions or share ideas in the [Discussions tab](../../discussions).
3. **GitHub Issues**: If you found a bug or have a feature request, file an [Issue](../../issues). Please check existing issues before creating a new one.
