# Help Center Ecosystem

## Implementation Status
- **Status:** Integrated Inline
- **Component:** `<Tooltip />` (`Tooltip.tsx`)

## Contextual Education
PixelSense does not rely on an external "Help Manual" website. Instead, help is delivered inline, exactly when the user needs it.
- **Settings:** Every setting (e.g., "Screen Content Analysis", "Fullscreen Media") features an inline tooltip explaining the exact behavior of the toggle.
- **Dashboard:** Metrics (e.g., "Comfort Score", "Environmental Light") feature tooltips explaining how the metrics are calculated (e.g., "Measured in lux. A normal office is around 300-500 lux.")

By providing inline help, users never need to leave the application to understand their configuration.
