# PixelSense v0.1.0-alpha - Release Notes

We are thrilled to announce the first Release Candidate of PixelSense!

## Features
- **Dynamic Brightness Control:** Automatically calibrates monitor brightness using DDC/CI.
- **Intelligent Visual Comfort:** Real-time compensation for visual complexity on-screen.
- **Interactive History Log:** Fully virtualized history logging to understand every background decision.
- **Configuration Maturity:** Instant backup, restore, and factory reset functionality.

## Breaking Changes
- None (Initial Release)

## Migration Notes
- Ensure your monitor supports DDC/CI via your OSD menu before installing.
